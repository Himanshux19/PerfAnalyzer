How to Obtain Your Uptrace DSN

Data Source Name for OpenTelemetry & Uptrace Ingestion
What is an Uptrace DSN?

The DSN (Data Source Name) authenticates your application and points your OpenTelemetry traces, metrics, and logs to your specific Uptrace project.

# Uptrace Cloud Format:
https://<project_token>@uptrace.dev/<project_id>
1
Log in to Uptrace
Navigate to https://app.uptrace.dev ↗ (or your self-hosted instance).
2
Create or Select a Project
Create a new project (e.g. Production API) or click on an existing project.
3
Copy the Project DSN
Go to Project Settings → DSN / API Keys or view the Setup instructions on Uptrace. Copy the full DSN URL.
4
Paste in PerfAnalyzer
Paste your DSN into the customizer bar or the monitor configuration modal. PerfAnalyzer encrypts it securely with AES-Fernet.
